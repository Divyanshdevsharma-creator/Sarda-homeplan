# Sarda Homeplan

Professional House Planning & Architectural Consultation Web Application.

## Key Features
- **Client Requirement Intake**: Interactive form with plot dimensions, room counters, Vastu consultation, and sketch upload.
- **Customer Portal**: Real-time project tracking, site visit scheduling & rescheduling, deliverable approvals ("Final the Map" / "Need Change"), notifications, and contractor handouts.
- **Admin Workspace**: Complete management of customer requests, site visits, architectural drawings, payments, and client directory.
- **Supabase Integration**: Auth, database tables, and real-time persistence.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Configure environment variables in `.env.local`:
```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your_supabase_publishable_key
```

3. Run the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```
